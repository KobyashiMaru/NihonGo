# 🌸 NihonGo! (日語通) - 零基礎日語學習與 AI 視訊會話平台

> 專為**零基礎起步**、配備 **MacBook / Apple 日式巧控鍵盤（Magic Keyboard JIS 佈局）**、以**通過 JLPT N3/N2** 為長遠目標打造的現代化互動式日語學習平台。

---

## 🚀 快速啟動指南 (Quick Start)

### 1. 前置環境準備
- 確認已安裝 **Node.js** (建議 v18 或以上版本) 與 **npm**。
- 檢查指令：
  ```bash
  node -v
  npm -v
  ```

### 2. 安裝依賴套件
在專案根目錄下執行：
```bash
npm install
```

### 3. 啟動本機開發伺服器
```bash
npm run dev
```
啟動成功後，終端機會顯示本地服務位址，請在瀏覽器中開啟：
👉 **http://localhost:5173/**

> [!TIP]
> 推薦使用 **Google Chrome**、**Microsoft Edge** 或 **macOS Safari** 開啟，可直接享受原生 Web Speech API 語音朗讀（TTS）與麥克風即時語音辨識（STT）！

### 4. 構建生產版本 (Production Build)
```bash
npm run build
npm run preview
```

### 1. 🌟 MacBook / Apple 日式巧控鍵盤（Magic Keyboard JIS）圖解新手教學
專為剛拿到日式鍵盤的使用者打造：
- **實體鍵盤即時感應器**：敲擊實體鍵盤，螢幕上的對應按鍵即刻高亮發光，並顯示該按鍵的日文功能。
- **三大核心神鍵剖析**：
  - **`英数` (Eisu)**：空白鍵左邊。按一下立即進入純半形英文模式，打網址、密碼不再手忙腳亂。
  - **`かな` (Kana)**：空白鍵右邊。按一下立即進入日文平假名模式，右手拇指一敲立刻能打日文。
  - **`Space (空白鍵)`**：假名打完後按 Space，智慧轉換為常用漢字詞組；連續按可展開候選字表。
  - **`倒 L 形巨大 Return 鍵`**：小指快速敲擊確認字詞（消除虛線下劃線）。
  - **免按 Shift 特殊符號**：`@` 在 P 鍵右邊、`:` 冒號在 ; 鍵右邊、`¥` 日圓符號在 Delete 鍵左邊。
  - **`control` 鍵位**：位於 A 鍵左側的人體工學黃金鍵位。
- **手把手 4 步驟 macOS 輸入法設定教學**：圖解如何進入「系統設定 ➔ 鍵盤 ➔ 文字輸入 ➔ 新增日本語（羅馬字）」。
- **Mac 專屬快捷鍵清單**：如 `Control + Shift + J`（平假名）、`Control + Shift + K`（片假名）。

### 2. 📞 Duolingo 風格 AI 擬真視訊通話 ("Sakura Call")
如同與真人好友進行 FaceTime 視訊通話：
- **擬真來電畫面**：專屬日式電話鈴聲、動態接聽與掛斷。
- **2D 動態虛擬對話夥伴（櫻花醬 Sakura）**：開口說話時動態嘴型張合與即時音波跳動，支援慢速（0.8x）與標準（1.0x）日語發音。
- **本機相機鏡頭（可選開關）**：右上角畫中畫預覽，享受真正與日本人面對面聊天的沈浸感。
- **即時字幕輔助**：支援振假名（讀音）、羅馬字拼音與中文即時翻譯開關。
- **救急錦囊（Hints）**：不知道回什麼時，點擊跳出 3 個初學者回答建議，點擊可練習或對著麥克風念出！
- **豐富的生活實戰情境**：
  1. *初次見面（自己紹介）*：名字、來自台灣、興趣動漫與美食。
  2. *東京咖啡廳點餐*：冰咖啡、尺寸、內用或外帶、Suica 刷卡結帳。
  3. *日本便利商店生存實戰*：便當加熱、購物塑膠袋、加點現炸炸雞。

### 3. ⌨️ JIS 打字特訓道場
- **五十音平假名單字打字**：練習 `asa (朝)`、`inu (犬)`、`sushi (すし)` 等肌肉記憶。
- **生活常用問候句**：打出 `こんにちは`、`ありがとうございます`。
- **漢字變換特訓**：輸入假名拼音 ➔ 按空白鍵選漢字 ➔ 按 Return 確認（例如輸入 `nihon` ➔ 按 Space 變 `日本` ➔ 按 Return）。
- 內建 50 音速查表（點擊可直接播放標準日語發音）。

### 4. 🎧 聽說讀寫四維訓練室
- **[聽] 聽力測驗**：針對日語中最容易混淆的「長短音（おじさん vs おじいさん）」、「促音停頓」與「便利商店金額結帳」進行聽力挑戰。
- **[說] 影子跟讀 (Shadowing)**：聆聽示範音訊後按下麥克風跟讀，AI 即時分析您的發音給予 0~100 分評分與反饋。
- **[讀] 分級日語閱讀**：精選 N5 短篇（我的早餐、東京電車搭乘攻略），支援點擊切換振假名、中文翻譯與整句朗讀。
- **[寫] 日式鍵盤句子重組**：將被打亂的詞塊用正確日語文法語序重組造句。

### 5. 🗺️ JLPT 闖關升級地圖 (目標 N3 / N2)
- **清楚的升級階段**：
  - **Stage 0 (入門)**：五十音與 Mac JIS 巧控鍵盤特訓
  - **Stage 1 (JLPT N5)**：日常生存生活日語（旅遊自由行無障礙）
  - **Stage 2 (JLPT N4)**：日常交流進階（普通體、授受動詞）
  - **Stage 3 (JLPT N3)**：自然流暢生活會話（聽得懂廣播、看懂短新聞）
  - **Stage 4 (JLPT N2)**：商務職場與深度交流（日企求職黃金標準）
- 模組化設計：後續可隨時擴充新單元、更高難度的聽力題庫與會話劇本！

| 領域 | 技術選型 | 說明 |

## 🧩 如何擴充新情境或新難度？

本專案採用**高度模組化的資料驅動架構**：
1. **新增視訊會話情境**：在 `src/data/conversationScenarios.ts` 中加入新的 `CallScenario` 物件，填入開場白與分支節點即可自動在介面中顯示。
2. **新增聽說讀寫題目**：在 `src/data/fourSkillsData.ts` 中添加新的聽力音訊或閱讀文章。
3. **增加 JLPT N3 / N2 單元**：在 `src/data/jlptCurriculum.ts` 的對應階段中新增 `modules`，解鎖更高難度的課程。
