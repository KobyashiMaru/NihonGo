# 日文五十音漢字字源與記憶對照表

## 2. 片假名易混淆字（筆順與方向）辨序指南

片假名當中有兩組字極易混淆，主要差異在於「落筆與提筆的方向」：

| 組別 | 片假名 | 發音 | 筆劃方向與記憶口訣 |
| --- | --- | --- | --- |
| **第一組**<br>**(從下往上提)** | シ | shi | 源自「三點水（氵）」，最後一筆由**左下往右上提**。 |
|  | ン | n | 只有兩筆，第二筆由**左下往右上提**。 |
| **第二組**<br>**(從上往下撇)** | ツ | tsu | 源自「川」，直筆由**上往下落筆**。 |
|  | ソ | so | 源自「曾」的頭部「丷」，由**上往下撇**。 |
